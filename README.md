# 🚀 Origo - Campus Social Discovery App

Origo is a hyper-localized social discovery platform designed for university campuses. It helps students find friends, dates, and communities based on "vibe" compatibility, powered by an AI matching engine.

> **Current Status**: MVP-Ready (Demo Build)  
> **Date**: January 2025

---

## 🏗 Architecture & Tech Stack

Origo is built as a modern full-stack application with a separated frontend, backend-as-a-service, and a dedicated ML microservice.

### **Frontend** (`origo-frontend`)
*   **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
*   **Styling**: [TailwindCSS](https://tailwindcss.com/) + [Framer Motion](https://www.framer.com/motion/) (Animations)
*   **State/Data**: Supabase Client

### **Backend** (`origo-backend`)
*   **Platform**: [Supabase](https://supabase.com/) (PostgreSQL)
*   **Auth**: Supabase Auth
*   **Realtime**: Supabase Realtime (Chat & Status)
*   **Logic**: Edge Functions (TypeScript) + Database Triggers

### **AI Engine** (`origo-ml`)
*   **Framework**: Python [Flask](https://flask.palletsprojects.com/)
*   **Model**: PyTorch (Custom User Embedding Network)
*   **Vector DB**: `pgvector` on Supabase

## 🛠️ Installation & Setup Guide

Follow these steps to run the complete system locally.

### Prerequisites
*   Node.js (v18+)
*   Python 3.8+
*   Supabase Account (for API URLs/Keys)

### 1. Database Setup
1.  Go to your Supabase Dashboard -> **SQL Editor**.
2.  Open `origo-backend/seed_ml.sql` and run the script to populate the database with demo users.

### 2. Run the Frontend
The user interface where you interact with the app.

```bash
cd origo-frontend
npm install
npm run dev
```

*   Access the app at: `http://localhost:5173`

### 3. Run the ML Service
The Python brain that handles vector generation and compatibility scoring.

```bash
cd origo-ml
pip install -r requirements.txt
python app.py
```

*   The service runs on: `http://localhost:5000`

## 🔑 Environment Variables

To make the system functional, ensure you have `.env` files created in both `origo-frontend` and `origo-ml`.

**Frontend (`origo-frontend/.env`):**
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

**ML Service (`origo-ml/.env`):**
```env
# Optional for local demo
SUPABASE_URL=your_supabase_url
SUPABASE_SERVICE_KEY=your_service_role_key
```
